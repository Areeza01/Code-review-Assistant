Project Overview

Intelligent Code Review Assistant is an AI-powered developer productivity platform designed to automate software code reviews.

The system evaluates Python and JavaScript source code, identifies potential bugs, security vulnerabilities, performance concerns, and maintainability issues.

Key Features

  • Static Python Analysis
  • JavaScript Analysis
  • Security Risk Detection
  • Code Quality Scoring
  • Review History Tracking
  • AI-Generated Recommendations
  • Analytics Dashboard

Technology Stack

  • FastAPI
  • SQLite
  • Python AST Analysis
  • Azure AI Foundry
  • HTML/CSS/JavaScript
